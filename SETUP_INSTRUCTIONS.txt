SECTION 3: INSTALLATION OPTIONS
================================================================================

OPTION A: RUN DIRECTLY (NO INSTALLATION)
----------------------------------------
1. Install Python 3.8+ from https://python.org
2. Download the package
3. Extract to a folder
4. Open Command Prompt in the folder
5. Run: pip install -r requirements.txt
6. Run: python app_launcher.py

OPTION B: BUILD WINDOWS EXECUTABLE
----------------------------------
1. Install Python 3.8+
2. Download and extract the package
3. Double-click "build_for_windows.bat"
4. Wait for build to complete (5-15 minutes)
5. Find JDHubSchoolManagement.exe in the "dist" folder

OPTION C: PROFESSIONAL INSTALLER (RECOMMENDED)
----------------------------------------------
1. Download Inno Setup from https://jrsoftware.org/isinfo.php
2. Install Inno Setup
3. Open installer.iss in Inno Setup Compiler
4. Press Ctrl+F9 to compile
5. Find the installer in the "installer" folder
6. Distribute the installer to clients

================================================================================

----------------------

4. Wait for the build to complete
5. Find your executable in "dist\JDHubSchoolManagement.exe"

Step 4: Test
------------
1. Go to the "dist" folder
2. Double-click "JDHubSchoolManagement.exe"
3. Verify it starts without errors

SECTION 8: PARENT PORTAL SETUP
================================================================================

The Parent Portal allows parents to view their child's information on their
phones. Here's how to set it up:

1. CONNECT TO NETWORK
   - Ensure the school computer is on the local network
   - The app will auto-detect the local IP

2. DISPLAY QR CODE
   - Go to Parent Portal in the sidebar
   - The QR code will be displayed automatically
   - The URL shown is: http://192.168.x.x:8000

3. PARENT ACCESS
   - Parent opens phone camera
   - Scans the QR code
   - Browser opens to the portal
   - Login with:
     * Username: Student's ID (e.g., SCH/2024/001)
     * Password: Parent's registered phone number

4. WHAT PARENTS CAN VIEW
   - Report cards
   - Fee balance
   - Payment history
   - Attendance
   - Announcements

FOR REMOTE ACCESS (INTERNET):
- Use ngrok to create a public URL
- Share the URL with parents via WhatsApp

SECTION 9: M-PESA CONFIGURATION
================================================================================

The M-Pesa integration allows parents to pay school fees via mobile money.

TO SETUP M-PESA:

1. GET SAFARICOM CREDENTIALS
   - Register at https://developer.safaricom.co.ke
   - Create an app
   - Get Consumer Key and Consumer Secret
   - Get your Business Till Number

2. CONFIGURE IN APP
   - Go to M-Pesa Settings
   - Enter your credentials:
     * Consumer Key
     * Consumer Secret
     * Business Till Number
     * Passkey

3. TEST PAYMENTS
   - Make a test payment
   - Verify it works

SECTION 10: TROUBLESHOOTING
================================================================================

PROBLEM: Application doesn't start
SOLUTION: 
- Ensure Python is installed
- Run: pip install -r requirements.txt
- Check for error messages in terminal

PROBLEM: QR code not scanning
SOLUTION:
- Ensure phone is on same Wi-Fi as school computer
- Try opening URL directly in browser
- Check if firewall is blocking

PROBLEM: M-Pesa payments failing
SOLUTION:
- Verify Safaricom credentials
- Check internet connection
- Ensure correct phone format (256...)

PROBLEM: License activation fails
SOLUTION:
- Verify Machine ID matches
- Contact JD Hub: 0754687597

PROBLEM: Parent can't login
SOLUTION:
- Verify student ID is correct
- Verify parent phone matches database
- Reset password if needed

PROBLEM: Reports not generating
SOLUTION:
- Install reportlab: pip install reportlab
- Check data exists for selected filters
